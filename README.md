RaktaSeva Connect 🩸🚑

Problem Statement

In medical emergencies, finding a specific blood group quickly is often difficult and time-consuming. Existing systems mainly depend on phone calls, social media posts, or manual communication, which can delay treatment during critical situations. There is a need for a smart digital platform that can connect blood donors, patients, and hospitals instantly to improve emergency response and save lives.

**Features**

•User Registration and Login using Firebase Authentication

•Auto Login functionality

•Blood donor search based on blood group

•Emergency blood request system

•Google Maps integration for location support

•User Profile page with logout option

•Firebase Realtime Database integration

•Clean and responsive UI

•Splash screen with custom app logo

**Tech Stack**

•Kotlin

•Android Studio

•Firebase Authentication

•Firebase Realtime Database

•Google Maps SDK

•XML UI Design

•Fused Location Provider API


**Installation Steps**

•Clone the repository:git clone https://github.com/yourusername/raktaseva.git

•Open the project in Android Studio.

•Connect Firebase to the project.

•Add your Google Maps API key in AndroidManifest.xml.

•Sync Gradle files.

•Run the project on an emulator or Android device.

•Run Command: ./gradlew installDebug
